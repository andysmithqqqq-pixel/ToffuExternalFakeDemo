Toffu External — Android-проект

Что включено:
- WebView-загрузчик с темой, логами и импортом .tcf;
- настоящая проверка `su` на Android;
- проверка пакета com.jekmant.matrplauncher и попытка запуска игры;
- разрешение на отображение поверх других приложений;
- плавающая плашка и перемещаемая демонстрационная панель;
- сборка APK через GitHub Actions без установки Android Studio на ПК.

Важно:
- Это проект, а не уже собранный APK.
- Нужен интернет и GitHub для облачной сборки.
- Оверлей — интерфейсный; игровые действия (aimbot/выдача валюты/вмешательство в процесс) не реализованы.
- Android может требовать вручную выдать разрешение «Показывать поверх других приложений».
- Пакет игры указан как com.jekmant.matrplauncher; если он другой, поменяйте его в MainActivity.java.
- Проверка `su` зависит от установленного root-менеджера и его настроек.

Сборка с телефона:
1. Создайте новый пустой репозиторий на GitHub в браузере телефона.
2. Загрузите содержимое этого ZIP в репозиторий (Add file → Upload files).
3. Откройте вкладку Actions, выберите “Build Toffu APK” и нажмите Run workflow.
4. После завершения откройте запуск workflow → Artifacts → скачайте ToffuExternal-debug.
5. Распакуйте архив артефакта и установите app-debug.apk. Android может попросить разрешить установку из браузера/файлового менеджера.

Если GitHub Actions сообщает об ошибке Gradle, запустите сборку повторно; если ошибка повторяется, пришлите лог.
